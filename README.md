# The Little Story Café

A romantic, responsive static website for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — visual design
- `script.js` — scroll reveals and final-note interaction
- `assets/` — replaceable movie poster images

## Add your movie images
Save poster images in `assets/` with these exact filenames:
- `jab-we-met.jpg`
- `dil-to-pagal-hai.jpg`
- `veer-zaara.jpg`
- `ddlj.jpg`
- `yjhd.jpg`
- `mohabbatein.jpg`

Use images you have permission to publish. If you don't add images, the cards still render with their dark poster background and alt text.

## Publish on GitHub Pages
1. Create a repository named `the-little-story-cafe` (or use an existing repository).
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. After deployment, GitHub displays your Pages URL under Settings → Pages.

No build step is required.
